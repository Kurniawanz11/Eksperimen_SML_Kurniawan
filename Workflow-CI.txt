Workflow CI/CD:

1. Checkout Repository
2. Setup Python 3.12
3. Check Environment
4. Install Dependencies
5. Set MLflow Tracking URI
6. Run MLflow Project
7. Upload to GitHub Artifacts

Perintah utama workflow:

mlflow run MLProject --env-manager=local

Status Workflow:
GitHub Actions berhasil dijalankan (Success).

GitHub Artifacts digunakan untuk menyimpan hasil workflow secara otomatis.
